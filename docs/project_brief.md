# Project Brief

## Scenario

An e-commerce management team wants a consolidated view of commercial performance and customer behaviour. Existing reporting focuses on total sales but does not explain customer retention, customer value, category performance, or the drivers behind changing revenue.

## Analyst Deliverable

Build a reproducible analysis that combines SQL, Python, Excel, and Power BI to answer management questions and produce an executive-ready dashboard.

## Core Deliverables

- Data-quality report
- SQL KPI queries
- Customer and product analysis
- Cohort retention analysis
- RFM segmentation
- Python EDA notebook
- Power BI dashboard
- Excel management summary
- One-page executive recommendations

## Success Criteria

The final project should allow a reviewer to understand the business problem, reproduce the analysis, inspect the logic behind each KPI, and connect every recommendation to evidence in the data.
